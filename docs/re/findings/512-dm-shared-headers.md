# F-512-4: Shared device-manager message and callback declarations

The incomplete device-manager source used headers containing only the message variants and APIs needed by its first 21 functions. This prerequisite extends the existing imported `include/revolution/bte/` headers with the declarations required by the complete unit, before changing implementations.

The BTA message union gains named signal-strength and ACL-change variants. Existing members retain their order and types; neither new member exceeds the existing 0x110-byte union extent. The signal-strength message is 0x0E bytes, with mask at 8, period at 0x0A and start flag at 0x0C. The ACL-change message is 0x12 bytes, with event at 8, busy level at 9, new-link flag at 0x0A and address at 0x0B. The two BTM result structures each occupy nine bytes, with status at 0, HCI status at 1, RSSI or link quality at 2 and address at 3. The configuration records for role management and compression each have three byte fields. Existing control-block layouts are unchanged.

The reference is Petari commit `e0ab141914921726a595573dc48d3f13d0922efe`, `src/RVL_SDK/bte/{bta_dm_int.h,bta_api.h,btm_api.h,bta_dm_co.h,hcidefs.h,bt_target.h,l2c_api.h}`. All newly imported constants, macro bodies, layouts and names come from that pinned reference. New BTM declarations retain their original byte-status return types. `bta_dm_co_get_compress_memory` returns `BOOLEAN`; `L2CA_SetIdleTimeout` takes two unsigned-short arguments and a byte flag. Target callback instruction streams confirm the field offsets and conversion widths. The full implementation is investigated separately and remains unselected until complete source-link verification.

A scratch compilation of the complete action unit gives exact non-relocation instruction streams for all 56 retained functions with these declaration additions. In particular, an implicit `int` return for the compression allocator inserted an extra byte conversion; declaring its original `BOOLEAN` return removes it. An implicit timeout prototype omitted a required unsigned-short conversion; the recovered `L2CA_SetIdleTimeout` declaration restores it. These instruction comparisons are diagnostics, not a complete linked acceptance claim.

Validation captures code, data, BSS sizes and relocation records for the existing partial `bta_dm_act.c`, partial `bta_dm_api.c` and matching `bta_sys_conn.c` source objects, then recompiles every registered source through `ninja all_source`. All section bytes, sizes and resolved relocation targets remain unchanged. The compiler renumbers two anonymous action-unit string labels by nineteen after parsing the additional declarations; their offsets remain `.data+0` and `.data+0x20`, with unchanged 30-byte and 29-byte strings. All external relocation names and types are unchanged. A normal full build and frozen-manifest verification check that all existing source-selected units remain valid. The pull request records command results and final rebased commit. No source function, split, symbol record, compiler selection or frozen fingerprint changes in this prerequisite; it adds no reconstructed code coverage.
