# F-492-1: SC system configuration

## Shared header correction

The target sensitivity getter at `0x802E98E0` matches the pinned Petari `SCGetBtDpdSensibility` implementation with a `u32` local and return type. It calls `SCFindU32Item` for item 30 and clamps the result to 1 through 5. The imported `include/revolution/sc.h` incorrectly declared the return type as `u8`; the existing WPAD caller stores the result in `u32`. Correct the declaration in a prerequisite header pull request before adding the SC sources.

Reference: [Petari scapi.c](https://github.com/SMGCommunity/Petari/blob/e0ab141914921726a595573dc48d3f13d0922efe/src/RVL_SDK/sc/scapi.c), CC0. Its compiled 0x68-byte instruction stream matches the target after masking relocation words; complete source and link acceptance remains pending.

## Traps

No new project-wide trap established during the header correction.
