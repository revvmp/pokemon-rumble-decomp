## Traps

- A native u16 mapping table can accidentally look like executable and
  data pointers when adjacent codepoints form a valid address. dtk inferred
  six false ADDR32 relocations, including one to an artificial internal
  symbol at 0x803691CE, and data scoring was 99.718216 despite identical
  payload bytes. Restore the complete 45-by-189 native array extent,
  remove the spurious internal boundary, and use the already established
  encoding-table noreloc attribute. The target's table has no relocations;
  corrected actual rodata scores 100% and the source-selected DOL is exact.
- Ending the rodata split directly at the two-byte-aligned array end makes
  dtk reject its automatic successor with Invalid alignment for split.
  Preserve the six native alignment bytes through 0x8036C440 as linker
  alignment, without inflating the array or adding source padding storage.
- Separate conversion if statements and an equivalent switch change the
  native lead-byte classifier. An ordinary else-if chain preserves its
  merged decision tree. Widening the byte-predicate local to u32 and keeping
  constant-left lower comparisons avoids byte-range folding, consistent
  with the earlier F-350-1 toupper finding.

- Union-merging append-only documentation from a newer isolated base can
  pull unrelated tail context into an older stacked candidate. Compare
  against the actual stack base and retain only the owned appended records;
  otherwise a source handoff can duplicate existing ledger rows and import
  findings paragraphs whose source changes are not in the candidate.
- A matching aggregate layout does not establish a matching copy expression
  or pointer qualification. The five volume-tail diagnostic candidates above
  establish the measured callback copy and initialization choices without
  casts, compiler flag changes, or production forcing helpers.
- Per-function instruction comparisons alone can conceal reordered source
  definitions. The complete volume audit additionally requires every native
  function offset and the entire relocated text section, including padding.
