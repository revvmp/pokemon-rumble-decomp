## Behavior and interfaces

The four original names are PFFAT32_ReadFATEntry, PFFAT32_WriteFATEntry, PFFAT32_WriteFATEntryWithBuf and PFFAT32_ReadFATEntryWithBuf. The buffered operations take a direct PF_CACHE_PAGE pointer, unlike the related VF page-pointer interface. The owning pf_fat32.h declares all four native signatures and reuses the canonical volume/cache records.

FAT entries occupy four little-endian bytes with28 significant cluster bits. Writes preserve the existing high four bits. Native mirror writes visit every active FAT and preserve the first error while continuing. Buffered writes flush the prior cached sector to the mirrors before reading a different sector. Reads retain the observed callback retry and mirror-selection behavior for driver error0x1000. The native routines omit the related VF null-volume and cluster-range checks.

PFFATFS_initializeFATFS tail-calls PFVOL_InitModule with its original configuration and parameter arguments. Its four-byte body is a relative branch, with the actual target80215EB0. It does not return a fabricated constant or the configuration unchanged.
