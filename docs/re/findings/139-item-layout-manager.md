# F-139-1: Original scope and recovered interfaces

Target wpse-v1 and unchanged frozen executable. The original REST inventory is 25 functions and 6,624 instruction bytes. CItem owns eight retained entries from 0x800C0C60 through 0x800C1218. CLayoutManager begins with its shared factory at 0x800C1220 and ends at 0x800C2678, including sixteen retained methods and generated container/shared-pointer helpers. The final original issue function at 0x800C2680 is a 76-byte standalone marker ordering predicate, referenced only as the sort callback in minimap Calc at 0x800C30D0. It therefore starts the next source unit before the survey factory boundary at 0x800C26D0. The complete minimap boundary requires coordination with #140 and #141; no outside bodies or splits have been adopted.

CItem's complete 0x104 declaration is already canonical from [F-115-4](115-enemy-info-pii-facility.md#f-115-4-complete-citem-base-contract-and-facility-consumer). LoadModel allocates a 220-byte CModel, builds an item.arc/ path, loads a resource descriptor and assigns the model; the current shared CModel header is incomplete and its outside implementation remains with first owner #318. A bounded complete contract is required before source integration, with existing consumer controls.

Original RTTI spells CLayoutManager and ILayoutManager. The implementation is 24 bytes: interface vptr at zero, sixteen-byte map from signed int IDs to shared ICalcDraw objects at four, and next ID at twenty, initialized to one. Its 40-byte vtable preserves destructor, Calc, inherited CalcMtx/CalcView, Draw, then Add, Get, Remove. Native Add assigns at the current ID and returns the postincremented ID. Get returns an empty shared pointer for a missing key; Remove reports whether an entry existed. Calc and Draw traverse entries in key order. The signed cmpw instructions in native Get/Remove prove signed int IDs; decompiler _DWORD views initially obscured signedness. Descriptive API/member names and Get const qualification are inferred pending exact source proof.

An outside ordinary C++ probe reproduces the 284-byte factory and 1,100-byte recursive tree destruction instruction streams with relocation-bearing words excluded. This is diagnostic evidence only: resolved targets, complete data/EH/layout and source integration remain unaccepted. Get(int) now also reproduces all 148 non-relocation-bearing instruction bytes after following the native signed comparison and present-first return branch. The shared map header currently lacks noncompact iterators, find, erase and subscript; an outside additive candidate is being derived against the actual native loops. It has not changed canonical headers or existing consumers.

## Traps
