# F-329-1: CLayout compact map storage prerequisite

Part of #329. This prerequisite adds no reconstructed function or progress credit.

## Native evidence

The CLayout constructor at `0x801CB1C0` initializes two trees at `this+0xAC` and `this+0xB8`. Instructions `0x801CB258â€“0x801CB26C` store zero size, zero root, and a begin pointer to the root slot for each tree, with twelve bytes between tree starts. The next member begins at `0xC4`. A comparator data member would make each tree sixteen bytes and contradict both these stores and the complete `0xE8` CLayout extent.

The first tree maps `std::string` to `nw4r::lyt::AnimTransform*`: `0x801D19DCâ€“0x801D1A74` fetches an animation resource, creates an animation transform through the SDK Layout virtual interface, and inserts the returned pointer into the tree at `0xAC`. The second tree maps `nw4r::lyt::Pane*` to `shared_ptr<CLayout::PaneMP>`: `0x801D2180` uses the input pane, or the SDK root pane when null, as its key. The existing CPpuEngine map of integer keys to lists retains sixteen-byte storage. CLayout's font map of strings to shared font owners also retains sixteen-byte storage.

## Declaration provenance and bounded implementation

Declaration-only inspection of [the reference map header](https://api.github.com/repos/KooShnoo/pokemon-rumble/git/blobs/e848d60771125018671cd41a65067aefdbc30d41) identifies `__map_transform` selecting a transformed representation for scalar mapped values or pointer keys with the standard comparator, and a stateless `__base_value_compare`. Declaration-only inspection of [the reference tree header](https://api.github.com/repos/KooShnoo/pokemon-rumble/git/blobs/7a1a6b32a2807b8606dc8e3d18821a9096472a90) identifies compressed comparator/root storage. No reference algorithm implementation was reused.

The independent implementation retains the existing map tree and its mangled type for the untransformed path. A separate compact tree stores the stateless comparator as an empty base, followed by size, root, and begin. Selection is bounded to default `less` with the scalar categories already represented by the project's MSL traits, or pointer keys. This does not claim complete MSL map support or enum classification. Recursive node destruction follows the existing project's tree ownership operations. Helper names are descriptive reconstruction names, not recovered original spellings.

## Traps

An empty comparator does not imply sixteen-byte map storage. The target's transformed map representation removes its storage cost; changing the existing untransformed tree globally would instead break CPpuEngine and the font map.

Whole object hashes can change solely because additional template declarations renumber CodeWarrior's anonymous local symbols. Check every section and resolved symbol attribute before classifying such a change; this case preserves every relocation record and all allocated bytes, and still requires the full frozen DOL comparison.
