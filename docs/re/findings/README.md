# Findings by contributors

Each new finding is one file here, named `<issue>-<slug>.md` with ID `F-<issue>-<n>`, where `<issue>` is the GitHub issue the work belongs to. Unique issue numbers keep IDs from colliding across parallel work, and separate files avoid merge conflicts. Use the record fields described in [findings](../FINDINGS.md). Put traps you hit, meaning a symptom plus a verified workaround, under a `Traps` heading in your file instead of editing `AGENTS.md`. Maintainers promote the project-wide ones. F-0001 to F-0010 remain in that file.
