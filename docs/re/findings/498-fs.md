# F-498-1: ISFS client unit

Target `wpse-v1`, `main.dol`. Tools: decomp-toolkit 1.8.4, objdiff-cli 3.8.2, CodeWarrior Wii/1.0 with the F-0007 SDK flags at default alignment.

## Boundaries

`RVL_SDK/fs/fs.c` covers the whole block: `.text` `0x802F3430`-`0x802F4C40`, `.data` `0x803DCAE8`-`0x803DCB10` (the IPC-arena error string), `.sdata` `0x804B8D98`-`0x804B8DA8` (`__fsFd`, `"/dev/fs"`) and `.sbss` `0x804B9A08`-`0x804B9A20`. `ipcProfile.c` ends at `0x802F342C`, and `Padclamp.c` begins at `0x802F4C40`.

## Source

Petari's `fs.c` (CC0) reproduces 27 of the 28 functions unchanged. The target also has `ISFS_GetUsageAsync` (`0x802F4340`), which Petari lacks. It mirrors `ISFS_GetUsage`, uses context function 4 so `_isfsFuncCb` dispatches to `_FSGetUsageCb`, and issues an asynchronous ioctlv 12. `ISFS_GetFileStatsAsync` compiles but is dead-stripped.

`include/revolution/fs.h` is now the only ISFS header the unit needs. It takes `IOSFd`, `IOSUid` and `IOSGid` from `private/iostypes.h` and `private/iosrestypes.h`, and it gains `ISFSStats`, the path argument structures and the remaining prototypes. Before this change, `revolution.h` pulled in this header and the separate Petari copy `revolution/fs/fs.h` alongside it, so their `ISFSFileStats` definitions conflicted.

The IPC client callees `IOS_CloseAsync`, `IOS_ReadAsync`, `IOS_Read`, `IOS_WriteAsync`, `IOS_Write`, `IOS_SeekAsync`, `IOS_Seek`, `IOS_Ioctl` and `IOS_IoctlvAsync` are named in `symbols.txt` only, so the unit links. Their addresses follow Petari's `ipcclt.c` order and the fs wrappers that call them.

## Result

All 28 functions and every data section compare at 100%. The unit is linked as `Matching`, and the full DOL verifies.

## Traps

- **Local declaration order picks registers.** `ISFS_GetUsageAsync` swapped the registers for the context and the name pointer until the context was declared before `dnPtr`. Petari's sibling functions do not settle the order; compare the permutations.
- **`revolution.h` includes `revolution/fs.h`.** Including `revolution/fs/fs.h` in any unit that also reaches `revolution.h`, for example through `ipc.h`, redefines the ISFS types. Use `revolution/fs.h`.
