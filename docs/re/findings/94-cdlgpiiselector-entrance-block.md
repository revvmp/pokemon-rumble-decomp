Target `wpse-v1`, immutable `orig/wpse-v1/main.dol`, analysed in the linked `build/wpse-v1/main.elf`, which verifies byte-identical. Issue #94 lists 24 functions in `.text` `0x80093F70`–`0x80095154`. All of them belong to `game/CDlgPiiSelector.cpp`, whose split, object line and first function belong to #91 ([F-91-1](91-cdlgpiiselector.md)). The file is compiled without inlining ([F-92-1](92-cdlgpiiselector-construction.md#f-92-1-the-file-is-compiled-without-inlining)). Slot numbers count from the first function word of a vtable, so slot `n` is at offset `8 + 4n`.

## F-94-2: reconstruction of five functions

`src/game/CDlgPiiSelector.cpp` now defines `IsShown(int)`, `IsMultiPlayerEntranceShown()`, `GetEntrancePPD` and `SetEntrancePPD` in the class body, as the other selector virtuals are ([F-93-4](93-cdlgpiiselector-calc-block.md#f-93-4-calcview-calcmtx-and-their-helpers)). They and `shared_ptr<CPiiPersonalData>()` (`0x80094CE0`) are at 100% in objdiff. So are two later-block template members they emit, `shared_ptr<CPiiPersonalData>::operator=` (`0x8009C0E0`) and `swap` (`0x8009C130`). The unit reports 47/530, and the full build verifies. `CDataPerPlayer::IsShown()` is declared but not defined, because its `bool` at 0x50 sits behind the `CPiiListFilterSort` member ([F-93-4](93-cdlgpiiselector-calc-block.md#f-93-4-calcview-calcmtx-and-their-helpers)). `IsShown(int)` therefore calls an undefined symbol, and `0x800941D0` is not emitted.

Two shape details matter:

- `IsShown(int)` must return early on `mIsPausing`, then return the `&&` chain. A single `||` expression tests the flag with the opposite branch and loads the result register earlier.
- `GetEntrancePPD` is one conditional expression whose false branch is a temporary `shared_ptr<CPiiPersonalData>()`, which accounts for the destroy flag in `r29`. CodeWarrior evaluates the channel (slot 8) before the type (slot 7) for `mEntrancePPD[type][channel]` in both functions.

`0x80089680`, the outside callee of `GetEntrancePPD`, is the `shared_ptr<CPiiPersonalData>` copy constructor. That copy was compiled with `retain` inlined (0x28 bytes), so it comes from an earlier unit built with inlining, while this file's out-of-line copy is 0x4C bytes and is dropped by the linker.

## Method

GNU objdump 2.42 on `build/wpse-v1/main.elf` and the rebuilt object, the generated assembly under `build/wpse-v1/asm/`, and Wii/1.1 with `cflags_game` through `ninja` and `tools/re/unitdiff.py`. No decompiler output was used.

## Traps

- **A weak copy in an earlier unit can be compiled differently.** The `shared_ptr<CPiiPersonalData>` copy constructor that the link keeps (`0x80089680`, 0x28 bytes) has `retain` inlined, but this no-inline file compiles a 0x4C-byte copy. Compare sizes before assuming an outside weak function is a different routine, and do not expect objdiff to pair it with this unit (F-94-2).
- **`a || (b && c)` and an early return compile differently.** For `IsShown(int)`, the single expression reversed the first branch. When a result register is set to 1 on one path and to 0 before an `&&` chain on the other, try an early `return true` (F-94-2).
