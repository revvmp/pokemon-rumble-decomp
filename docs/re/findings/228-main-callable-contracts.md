## Traps

- A callback wrapper's indirect boolean result can require an explicit generic result conversion. Native RTTI and the full sixty-byte invocation distinguish it from the twenty-byte direct-return implementation; do not infer the implementation flags from another arity.
- An instantiation driver proves the retained template body and ABI, but does not reconstruct its startup caller or prove whole-unit physical placement. Keep those acceptance gates separate.
- Additional template declarations can advance the compiler's numeric `__FUNCTION__$N` identifiers. The strict full-object gate initially rejected CLayout's label `5684` becoming `5711`; both symbols still identify the same nine-byte payload at the same section offset with identical attributes and actual relocation destinations. Narrowly normalize that numeric identifier only after proving the unchanged bytes and targets; retain the failed comparison and raw object difference.
