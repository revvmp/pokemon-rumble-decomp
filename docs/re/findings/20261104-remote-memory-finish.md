## Traps

- Equal function percentages can conceal a useful allocation change. Moving only the FinishWrite delay declaration left its score unchanged, but a trace showed the delay acquiring the correct register while the alarm and message shifted. Moving all three declarations after the copy scheduling fix completed the function. Inspect the operands rather than dismissing an equal-score candidate.
- A shared inline flag helper can improve one caller while changing another caller's load reuse. The explicit cached flags form improves BeginRead but regresses FinishRead. Compare every function before retaining a helper change.
- A known constant can defeat output-reference controls that preserve dynamic field loads. The successful composite-state control uses the enum and integer members of the same union. The independent 0x200 constant and OR result survive without additional instructions; plain enum locals and output references did not preserve them in these callers.
- An apparent instruction-order difference can come directly from the expression tree. FinishRead's OR and clear-mask operations commute, but the target performs OR first. Correct the source expression before pursuing a scheduler control.
